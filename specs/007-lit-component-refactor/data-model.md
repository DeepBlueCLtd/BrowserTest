# Data Model: Lit Component Refactor & Testability Improvements

**Feature**: 007-lit-component-refactor
**Date**: 2025-11-25

## Overview

This feature is an **internal refactor**—no changes to the core data model. All existing types from `src/types/contracts.ts` remain unchanged.

## New Internal Types

These types are introduced for internal organization only. They are not persisted or part of the public API.

### Helper Function Types

#### QuestionInputSpec

Describes how to render an input control for a quiz question.

```typescript
/**
 * Specification for rendering a question input control.
 * Generated by question-input service, consumed by enhancers.
 */
interface QuestionInputSpec {
  /** Input type: 'select' for MCQ, 'text' for numeric */
  type: 'select' | 'text';

  /** Current/default value */
  value: string;

  /** Options for MCQ (undefined for numeric) */
  options?: string[];

  /** Placeholder text for numeric input */
  placeholder?: string;

  /** Whether the input should be disabled */
  disabled?: boolean;
}
```

#### StudentAnswerDisplay

Formatted student answer for instructor review display.

```typescript
/**
 * Student answer formatted for display in instructor review.
 * Generated by answer-display service, consumed by enhancers.
 */
interface StudentAnswerDisplay {
  /** Student's display name */
  name: string;

  /** Last 4 characters of service ID */
  serviceIdLast4: string;

  /** The answer value */
  answer: string;

  /** Whether the answer was correct */
  success: boolean;

  /** Human-readable timestamp */
  formattedTimestamp: string;
}
```

#### StatusIndicator

R/A/G status indicator value.

```typescript
/**
 * Status indicator for quiz progress.
 */
type StatusIndicator = 'red' | 'amber' | 'green';
```

### Modal Component Types

#### ModalProps

Common properties for all modal components.

```typescript
/**
 * Base properties for modal components.
 */
interface ModalProps {
  /** Whether the modal is open */
  open: boolean;

  /** Whether the modal can be closed by user action */
  closable?: boolean;

  /** Title displayed in modal header (optional) */
  title?: string;
}
```

#### ScoresModalData

Data passed to the scores modal.

```typescript
/**
 * Student scores data for display in scores modal.
 * Uses existing StudentRecord type from contracts.
 */
interface ScoresModalData {
  /** Array of student records to display */
  students: StudentRecord[];

  /** Current release ID for filtering */
  release: ReleaseId;
}
```

## Existing Types (Unchanged)

The following types from `src/types/contracts.ts` are used but not modified:

- `StudentRecord` - Student data with answers
- `AnswerRecord` - Individual answer with timestamp
- `PageData` - Per-page quiz/analysis data
- `QuizQuestion` - Parsed quiz question structure
- `ReleaseId`, `ServiceId`, `PageId` - Identity types

## State Transitions

No new state transitions. Modal open/close is handled via Lit reactive properties:

```
Modal States:
  closed → open (user action or programmatic)
  open → closed (Escape key, backdrop click, or close button)
```

## Relationships

```
QuestionInputSpec
  └── Used by: quiz-table.ts enhancer
  └── Created by: question-input.ts service

StudentAnswerDisplay
  └── Used by: quiz-table.ts, analysis-table.ts enhancers
  └── Created by: answer-display.ts service

ModalProps

```

## Validation Rules

### QuestionInputSpec Validation

| Field | Rule |
|-------|------|
| `type` | Must be 'select' or 'text' |
| `options` | Required when type is 'select', must have 2+ items |
| `placeholder` | Optional, string |

### StudentAnswerDisplay Validation

| Field | Rule |
|-------|------|
| `name` | Non-empty string |
| `serviceIdLast4` | Exactly 4 characters |
| `answer` | String (may be empty for unanswered) |
| `formattedTimestamp` | Valid formatted date string |

## Migration

No migration required—this is an internal refactor with no persisted data changes.
