Development Demo with Storage Monitor

🔧 Development Mode Active

The storage monitor is visible on the right side of the screen. You can:

  • Press Ctrl+Shift+D to toggle it on/off
  • Watch storage update in real-time as you interact with the quiz
  • Expand entries to see nested JSON data
  • Clear individual keys or all storage

Note: The storage monitor only appears when debug mode is enabled via the data-debug="true" attribute on the script tag.
