Authoring Guidelines

  • Class attribute: Tables must have the qd-analysis class
  • Read-only cells: Add style="background-color: #xxx" to make cells read-only
  • Editable cells: Leave cells WITHOUT any background-color style to make them editable
  • Maximum: ONE analysis table per page
  • Cell content limit: Maximum 500 characters per cell
  • Auto-save: Student entries are automatically saved as they type
  • Uniqueness: Each cell gets a unique key based on position and content hash
