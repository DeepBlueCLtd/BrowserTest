Authoring Guidelines

  • Class attribute: Tables must have both qd-quiz and qd-page classes
  • Columns: Exactly 3 columns required: Question | Answer | Detail
  • MCQ format: Use <ol> (ordered list) in the Detail column
  • MCQ answers: Must be 1-indexed (first option = 1, not 0)
  • Numeric format: Provide tolerance as a plain number in the Detail column
  • Maximum: ONE quiz table per page
  • Mixing types: You can mix MCQ and numeric questions in the same table
